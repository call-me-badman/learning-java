## Detailed Curriculum

Click a phase to expand it.

<details open>
<summary><b>Phase 1: Java Core Fundamentals</b> <img src="https://img.shields.io/badge/level-zero-blue"/></summary>

<br/>

Master the basic syntax and structural building blocks of the language.

- **Setup & Syntax:** install the JDK, set up IntelliJ IDEA, write `HelloWorld.java`, learn variables, data types and operators.
- **Control Flow:** `if-else`, `switch`, and `for` / `while` / `do-while` loops.
- **Object-Oriented Programming:** classes and objects, inheritance, polymorphism, encapsulation, abstraction (interfaces and abstract classes).
- **Memory Management:** how the Stack and Heap work.

</details>

<details>
<summary><b>Phase 2: Advanced Java Concepts</b> <img src="https://img.shields.io/badge/level-intermediate-yellow"/></summary>

<br/>

Write efficient, clean, modern code.

- **Data Structures:** the Collections Framework (`List`, `Set`, `Map`, `Queue`).
- **Exception Handling:** `try-catch-finally`, `throw` / `throws`, custom exceptions.
- **Java 8+ Features:** Lambdas, Streams API, `Optional`, modern Date/Time API.
- **Concurrency:** Threads, `Runnable`, `ExecutorService`, basic synchronization.

</details>

<details>
<summary><b>Phase 3: The Ecosystem & Data Layer</b> <img src="https://img.shields.io/badge/level-intermediate-yellow"/></summary>

<br/>

Learn the tools professional enterprise developers use daily.

- **Build Tools:** dependencies and builds with Maven or Gradle.
- **Database Basics:** SQL queries and JDBC.
- **ORM Frameworks:** Hibernate and JPA.
- **Testing:** unit tests with JUnit 5, mocking with Mockito.

</details>

<details>
<summary><b>Phase 4: The Spring Boot Revolution</b> <img src="https://img.shields.io/badge/level-advanced-orange"/></summary>

<br/>

Move from standalone applications to robust web APIs.

- **Spring Core:** Dependency Injection (DI) and Inversion of Control (IoC).
- **Spring Boot:** rapid applications with auto-configuration.
- **Spring Web:** `@RestController`, HTTP methods (GET, POST, PUT, DELETE), validation.
- **Spring Data JPA:** repositories with almost no boilerplate.
- **Spring Security:** basic authentication and JWT.

</details>

<details>
<summary><b>Phase 5: Distributed Systems & Microservices</b> <img src="https://img.shields.io/badge/level-hero-purple"/></summary>

<br/>

Scale by splitting your application into independent, cooperating services.

- **Architecture:** service boundaries, pros and cons.
- **Service Discovery:** Netflix Eureka.
- **API Gateway:** routing, CORS and auth with Spring Cloud Gateway.
- **Inter-Service Communication:** OpenFeign (sync), Apache Kafka or RabbitMQ (async).
- **Resilience:** circuit breakers with Resilience4j.
- **Centralized Configuration:** Spring Cloud Config Server.

</details>

<details>
<summary><b>Phase 6: Observability, Cloud & Deployment</b> <img src="https://img.shields.io/badge/level-hero-purple"/></summary>

<br/>

Bring your application to production and keep it healthy.

- **Containerization:** Docker.
- **Observability:** Spring Boot Actuator, Prometheus, Grafana.
- **Distributed Tracing:** Micrometer Tracing and Zipkin.
- **Deployment (next steps):** AWS, Azure, GCP, or Kubernetes.

</details>

## Recommended Tech Stack

| Category | Technology |
|---|---|
| Language | Java 17 or Java 21 (LTS) |
| IDE | IntelliJ IDEA (Community or Ultimate) |
| Build System | Maven |
| Frameworks | Spring Boot 3.x, Spring Cloud |
| Databases | PostgreSQL, MySQL, Redis (caching) |
| Messaging | Apache Kafka or RabbitMQ |
| DevOps & Infra | Docker, Git, GitHub Actions |

## How to Use This Repository

1. Fork this repository to your own profile.
2. Create a folder per phase (e.g. `01-java-core/`, `04-spring-boot/`) for your practice code.
3. Commit daily and tick off the checklist below.
